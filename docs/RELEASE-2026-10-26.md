## What changed

The standalone reader now bundles pinned Chart.js 4.6.1 and Cytoscape.js 3.34.4
for the already restricted `chartjs` and `cytoscape` profiles when the host enables
`visualizations.interactive`. The Markdoc core remains library-free and continues
to emit the deterministic static SVG, exact table and source. Adapter markup adds
an empty mount host and an inert, escaped data template; the browser re-parses the
profile before either library receives it.

Chart.js is limited to validated bar/line data with animation off, fixed styling
and no authored callbacks, plugins or HTML tooltips. Cytoscape maps node/edge ids
to namespaced ids, uses a fixed style and deterministic breadth-first layout, and
loads no external images, stylesheets or network layouts. Graph ids are unique per
document. If parsing or mounting fails, the static SVG remains visible; print
always switches back to the static SVG. No global `Chart` or `cytoscape` is exposed.

Required accessibility descriptions can now be authored in ordinary Markdown:

```yaml
---
document:
  visualizations:
    descriptions:
      1: Measured counts by category
---
```

Host-supplied descriptions still take precedence. Vega-Lite and Plotly remain
static; Mermaid and PlantUML remain inert source. No remote renderer, authored
JavaScript, new origin, font request or network data source was added. The bundle
license inventory pins Chart.js, Cytoscape.js and `@kurkle/color` with MIT notices.
